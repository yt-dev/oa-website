# Marketing images

Drop product screenshots here. The site shows a styled **placeholder** until each file exists.

| File | Used for | Suggested size |
|------|----------|----------------|
| `hero-console.webp` | Hero product shot | 1920×820 (wide) |
| `feature-rooms.webp` | Gallery — room booking | 1280×720 |
| `feature-tv.webp` | Gallery — TV dashboard | 1280×720 |
| `feature-visitors.webp` | Gallery — visitor welcome | 1280×720 |
| `og-default.webp` | Open Graph / social share | 1200×630 |

Tips:

- Prefer **WebP** (or PNG). Keep under ~300KB for hero, ~150KB for gallery.
- Avoid confidential staff data in screenshots.
- After adding files, rebuild or refresh the dev server.

Optional formats also work if you update paths in `Hero.astro` / `Gallery.astro` (e.g. `.png`).
